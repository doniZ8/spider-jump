SPIDER JUMP

Управление:
A/D или стрелки — движение.
ЛКМ / Space / W / ↑ — прыжок.

Экономика:
Каждые 5 платформ = +5 монет.

Бусты:
🚀 Джетпак — 50 монет, поднимает игрока на 50 платформ.
🕷️ Тройной прыжок — 25 монет, позволяет сделать 3 прыжка подряд.
❤️ Доп. жизнь — 200 монет, продолжает игру после падения.
