## Supabase

1. Создай таблицу через supabase.sql в SQL Editor.
2. Открой config.js.
3. Вставь Project URL и anon/public/publishable key.

Никогда не вставляй service_role key в браузер.

## Важное про онлайн-лидерборд

Эта версия использует клиентскую отправку результатов. Для полностью защищённого соревновательного рейтинга нужна серверная проверка результата (например, Supabase Edge Function + server-side validation).


## Версия 3 — управление и экономика
- Магнит тянет монеты строго к персонажу.
- Монеты зарабатываются значительно сложнее.
- После окончательной смерти обнуляются монеты и все бусты текущего забега.
- Новый забег также начинается без монет и бустов.
- A/D/W работают независимо от раскладки через KeyboardEvent.code; добавлена поддержка Ф/В/Ц.
- Комбо изменяется при приземлении, а не уменьшается в полёте.
- На мобильном свайп влево/вправо по игровому полю управляет движением; короткий тап по полю — прыжок.
