SPIDER JUMP — бесконечная версия + магазин + глобальный лидерборд

ЧТО УЖЕ ЕСТЬ
- Бесконечная генерация платформ.
- Каждые 100 платформ сложность повышается: расстояния уменьшаются, платформы становятся уже.
- Переходы: джунгли → снег → город.
- Камера плавная; фон не трясётся.
- Между персонажем и платформой нет искусственного визуального "зазора": персонаж приземляется непосредственно на верхнюю поверхность.
- Реалистичная процедурная компьютерная графика без случайных перерисовок: многослойный фон, туман, здания, снег, растительность, свет, материалы платформ, детализированный персонаж.
- Магазин с анимациями.
- Купленные бусты сохраняются через localStorage.
- Jetpack: 50 монет, +50 платформ.
- Triple jump: 25 монет.
- Extra life: 200 монет.
- Монеты начисляются каждые 5 платформ.
- Глобальный онлайн-лидерборд через Supabase.

ВАЖНО ПРО ГЛОБАЛЬНЫЙ ЛИДЕРБОРД
Для настоящего общего рейтинга всех игроков нужен сервер. В этой версии используется Supabase.

ШАГ 1. СОЗДАЙТЕ SUPABASE
1. Откройте https://supabase.com/ и создайте бесплатный проект.
2. Откройте SQL Editor.
3. Скопируйте содержимое файла supabase.sql и выполните его.
4. Откройте Project Settings → API.
5. Скопируйте Project URL и anon/public key.

ШАГ 2. ПОДКЛЮЧИТЕ ИГРУ
Откройте config.js:
window.SPIDER_CONFIG = {
  SUPABASE_URL: "ВАШ_PROJECT_URL",
  SUPABASE_ANON_KEY: "ВАШ_ANON_KEY"
};

Не используйте service_role key в браузере. Нужен только anon/public key.

ШАГ 3. GITHUB PAGES
Загрузите в корень репозитория:
index.html
style.css
game.js
config.js
supabase.sql
.nojekyll
README.txt

GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
После публикации откройте адрес вида:
https://USERNAME.github.io/REPOSITORY/

СОХРАНЕНИЕ БУСТОВ
Покупки хранятся на устройстве игрока в localStorage. Это удобно для прогресса между заходами с одного браузера.
Если нужно хранить инвентарь/монеты на аккаунте игрока на сервере, потребуется авторизация (например, Supabase Auth) — это отдельный слой.

БЕЗОПАСНОСТЬ ЛИДЕРБОРДА
В демо-версии клиент может отправить произвольный score, потому что игра работает полностью в браузере. Для защищённого соревновательного рейтинга нужен серверный endpoint/Edge Function, который проверяет результат, скорость прохождения и другие игровые события. Не доверяйте score из POST-запроса как доказанному результату.

ЕСЛИ НУЖНА ЕЩЁ БОЛЕЕ РЕАЛИСТИЧНАЯ ГРАФИКА
Следующий шаг — заменить процедурные слои на подготовленные WebP/PNG ассеты (фон по биомам, спрайты персонажа, платформы, частицы). Текущая версия специально не требует внешних ассетов и работает как статический сайт.


ULTRA-ВЕРСИЯ
- 2.5D procedural rendering с динамическим освещением, атмосферой и параллаксом.
- Частицы: пыль, паутина, импульсы и огонь джетпака.
- WebAudio звуки прыжка, монет, столкновений и боссов.
- Новые зоны после 400 платформ и специальные зоны после каждого 1000.
- Каждые 100 платформ повышается сложность: платформы уже и промежутки меньше.
- Хранители появляются каждые 500 платформ и дают 50 монет после победы.
- Магазин и инвентарь сохраняются в localStorage.
- Глобальный лидерборд остаётся через Supabase.

Примечание: графика здесь процедурная и не требует скачивания внешних ассетов. Для уровня коммерческой 3D-игры можно следующим этапом подключить WebGL/Three.js и полноценные 3D-модели/текстуры.
